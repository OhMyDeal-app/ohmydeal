# OhMyDeal Beta 0.5 — инструкция

1. В Supabase → SQL Editor → New query вставьте содержимое `SETUP_BETA_05.sql` и нажмите Run. Должно быть `Success. No rows returned`.
2. В GitHub в ветке `main` замените файлы `main.jsx`, `style.css` и добавьте `supabase.js` из этого архива. Остальные файлы можно оставить как есть. Netlify должен запустить сборку автоматически.
3. В Supabase → Authentication → Providers убедитесь, что Email включён. При включённом Confirm email письмо с подтверждением обязательно.
4. Откройте сайт, создайте ТЕСТОВЫЙ аккаунт, войдите, создайте тестовый объект и перезагрузите страницу. Проверьте сохранение.

**Важно:** Beta 0.5 использует дополнительную таблицу `omd_user_data` с JSON для безопасной синхронизации существующего интерфейса. 15 основных таблиц пока не используются интерфейсом — их подключим поэтапно. Старые данные из localStorage автоматически не переносятся. В новой версии нет совместного каталога, модерации и Telegram-авторизации. Не загружайте реальные паспортные данные и конфиденциальные документы. Публичный publishable key в `supabase.js` допустим для клиентского приложения, но secret/service-role ключи туда добавлять нельзя.

**Проверка:** локальная сборка не была завершена в среде подготовки из-за недоступной установки npm-пакетов. Если Netlify сообщит ошибку, пришлите лог.
