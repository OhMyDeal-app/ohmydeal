# OhMyDeal Beta 0.7.1

- Фотографии теперь можно выбирать прямо в форме создания и редактирования объекта (до 20 файлов, максимум 10 МБ каждый).
- Фотографии загружаются в приватный бакет `omd-property-photos` перед сохранением карточки. Если загрузка не удалась, карточка не меняется и отображается ошибка.
- Добавлено поле «Комментарий агента» для внутренних заметок.
- Комиссия и доля партнёра принимают процент или фиксированную сумму в USD. Старые процентные значения сохранены.
- Обложка — первое фото, миниатюра карточки использует подписанную ссылку для приватного изображения.

## Установка
Распакуйте архив и загрузите файлы в корень GitHub-репозитория в ветку main. Дополнительный SQL не требуется, если `SETUP_BETA_07.sql` уже успешно выполнен.

## Ограничения
Партнёрская публикация пока не включена. Комментарии доступны только в личном интерфейсе; полноценное разграничение прав для партнёрских карточек требует отдельной серверной модели. Перестановка фотографий пока не реализована.
