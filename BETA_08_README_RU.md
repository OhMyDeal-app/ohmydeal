# OhMyDeal Beta 0.8 — тестовая сборка общего каталога

## Что реализовано
- Отдельные таблицы профилей агентов и опубликованных карточек с RLS.
- Проверка статуса `verified` на сервере; агент не может подтвердить себя самостоятельно.
- Вкладка «Партнёры», контакт автора, комиссия и доля партнёра.
- Публикация и снятие карточки вручную; существующая личная CRM не мигрирует и не открывается другим.
- Добавление партнёрской карточки в личный список подборки (не клиентская отправка).

## Что НЕ реализовано
- Просмотр чужих фото: оригиналы остаются в закрытом хранилище. Не открываем их прямыми ссылками.
- Серверные водяные знаки, защищённые превью, клиентская веб-ссылка и PDF — отдельная следующая итерация.
- Автоматическая синхронизация правок и статусов личной карточки с опубликованной: после изменения нажмите «Опубликовать» снова, а при снятии с продажи — «Снять с каталога».
- Проверка на реальном Supabase с двумя агентами: обязательна перед рабочим запуском.

## Установка (только после резервного копирования и проверки SQL)
1. Сохраните резервную копию личных данных из «Настройки».
2. Сначала проверьте `SETUP_BETA_08.sql` на тестовом проекте Supabase, затем при одобрении примените на рабочем.
3. Администратор вручную проверяет агента и устанавливает `verified=true` через защищённую админ-процедуру. Не выдавайте пользователям service-role ключ.
4. Загрузите файлы проекта в GitHub, дождитесь успешного деплоя Netlify.
5. Создайте тестовые аккаунты A и B. Убедитесь, что B не видит личные записи A, не может публиковать до верификации и видит только разрешённую карточку после верификации.

**Внимание:** эту сборку нельзя считать проверенной для продуктивного запуска без двухаккаунтного теста и успешной сборки. Не публикуйте реальные объекты до проверки.
