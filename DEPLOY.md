# OhMyDeal — публикация тестовой версии

## Вариант 1: GitHub + Vercel (рекомендуется)
1. Создайте новый приватный репозиторий на GitHub и загрузите в него содержимое папки `ohmydeal-beta` (файлы `package.json`, `index.html`, папку `src` и т. д., **не внешнюю папку**).
2. На vercel.com выберите Add New > Project > Import Git Repository и подключите репозиторий.
3. Framework Preset: Vite; Build Command: `npm run build`; Output Directory: `dist` (эти значения уже заданы в `vercel.json`).
4. Нажмите Deploy. Vercel установит зависимости и соберёт приложение на своей стороне.
5. Откройте выданную HTTPS-ссылку на iPhone. В Safari: Поделиться > На экран «Домой».

## Вариант 2: GitHub + Netlify
1. Импортируйте репозиторий через Add new project > Import an existing project.
2. Конфигурация сборки уже задана в `netlify.toml`: `npm run build`, публикация `dist`.
3. Запустите Deploy. Откройте HTTPS-ссылку на телефоне.

## Локальная проверка
Node.js 20+; `npm install`; `npm run dev`.

## Ограничения этой версии
- Данные сохраняются только в `localStorage` конкретного браузера и не синхронизируются между устройствами.
- Регистрации и общего каталога пока нет. Демо-объекты — примеры, а не проверенные предложения.
- AI — демонстрационный ответчик; договоры и загрузка документов не работают.
- Не вводите реальные паспортные данные, телефоны клиентов или конфиденциальные сведения.
- Сборка не была проверена локально: установка npm-пакетов в текущем окружении не завершилась. Хостинг выполнит сборку, и ошибки, если возникнут, будут видны в логах.
