# OhMyDeal Beta 0.7 — Мои объекты

## Установка
1. Сначала выполните `SETUP_BETA_07.sql` в Supabase → SQL Editor → Run.
2. Загрузите файлы архива в корень GitHub репозитория, заменив совпадающие.
3. Дождитесь Netlify Published и обновите страницу приложения.

## Что добавлено
- Упрощённая карточка вторички: цена, площадь, этаж, планировка, описание.
- Статус объекта, видимость, комиссия и доля партнёра.
- Загрузка до 20 фото по 10 МБ в приватный Supabase Storage из карточки уже созданного объекта.
- Галерея фото, приватные временные ссылки для просмотра.
- Существующая CRM и JSON-синхронизация сохранены.

## Важно
- Видимость «Партнёры» и «Все агенты» пока только поля карточки. Реальной публикации для других агентов нет: потребуется отдельная таблица объектов и RLS.
- Публикация на MyHome, SS.ge и Korter.ge пока не реализована.
- Каталог новостроек пока демонстрационный; синхронизация Google Drive не реализована.
- Загруженные фотографии остаются в Storage даже после удаления карточки. Очистку добавим в следующей версии.
- Не удаляйте `omd_user_data` и не запускайте старые SQL-скрипты повторно.
