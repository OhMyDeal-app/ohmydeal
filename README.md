# OhMyDeal Beta 0.4

Мобильное React/Vite веб-приложение для тестирования интерфейса OhMyDeal.

## Новое
- Единый аккуратный адаптивный экран карточек объектов, клиентов, событий и задач.
- Создание, редактирование и удаление объектов, клиентов, событий и задач.
- Связь задач с клиентами, статусы задач.
- Сохранённые объекты (подборки).
- Локальные фото своих объектов (до 3 файлов по 1 МБ).
- Экспорт/импорт JSON резервной копии.
- Демонстрационный OMD AI.

## Запуск
`npm install` затем `npm run dev`.

## Netlify
Build command: `npm run build`, publish directory: `dist`. При загрузке в GitHub файлы `index.html`, `main.jsx`, `style.css`, `package.json` должны находиться **в корне** репозитория.

## Важно
Данные сохраняются только в localStorage текущего браузера. Нет регистрации, серверной базы, настоящего ИИ и обработки договоров. Не вводите реальные паспортные данные или конфиденциальные сведения клиентов. Образцы объектов и событий демонстрационные, не реальные предложения или анонсы.
