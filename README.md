# OhMyDeal Beta 0.1

Рабочий мобильный прототип React + Vite. Интерфейс на русском языке.

## Запуск

1. Установите Node.js 20+.
2. Откройте папку проекта в терминале.
3. Выполните `npm install`.
4. Выполните `npm run dev`.
5. Откройте адрес, который покажет Vite (обычно http://localhost:5173).

Для проверки на телефоне откройте адрес локальной сети, который покажет Vite, при подключении телефона и компьютера к одной Wi-Fi сети. Для публичного адреса нужен хостинг с HTTPS.

## Что работает

- 5 разделов и адаптивная мобильная навигация.
- Добавление и удаление собственных объектов.
- Добавление и удаление клиентов CRM.
- Добавление, выполнение и удаление задач.
- Поиск объектов и клиентов.
- Локальное сохранение данных в `localStorage`.
- Демонстрационный OMD AI: отвечает на простые вопросы о количестве записей.

## Пока не реализовано

- Регистрация, Supabase, общая база агентов и синхронизация между устройствами.
- Настоящий AI, загрузка паспортов, создание договоров DOCX/PDF.
- Платежи, тарифы, push-уведомления, модерация и полноценная биржа лидов.

**Внимание:** это локальная демоверсия, не загружайте в неё реальные персональные данные клиентов. Информация хранится только в браузере устройства и может быть удалена очисткой данных браузера.
