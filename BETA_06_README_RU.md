# OhMyDeal Beta 0.6

Обновление на базе опубликованной Beta 0.5.

- Нажатие на счётчики на главной открывает объекты, CRM или календарь.
- В карточке клиента появилась история взаимодействий (звонки, сообщения, встречи, показы и заметки).
- Задача, созданная из карточки клиента, автоматически привязывается к нему и отображается в календаре.
- Заголовок браузера обновлён до Beta 0.6.
- Авторизация и существующее облачное хранение через Supabase сохранены без изменений.

## Публикация

Загрузите файлы из архива в корень ветки main на GitHub (не сам ZIP). Netlify автоматически соберёт сайт. SQL запускать не требуется.

## Проверка

1. Убедитесь, что прежний тестовый клиент на месте.
2. Нажмите на счётчик клиентов — откроется CRM.
3. Откройте клиента, добавьте запись в историю.
4. Из карточки клиента создайте задачу, проверьте связь и календарь.
5. Перезагрузите сайт, проверьте сохранение записей.

Внимание: Beta 0.6 всё ещё хранит данные аккаунта одним JSON-документом в omd_user_data. При одновременном редактировании с разных устройств возможна перезапись. До отдельной проверки безопасности используйте тестовые данные.
